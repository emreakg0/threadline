# Productivity App Starter

Minimal development scaffold for manual development with the user's own coding tools.

## Scope

The user requested scaffolding only: React, TypeScript, Vite, Tailwind CSS,
Node.js, Express, and a simple placeholder homepage.
Do not add productivity features, external APIs, authentication, or database
usage unless explicitly requested. Keep the project clean and GitHub-compatible.

## Run

- Frontend workflow: `artifacts/productivity-app: web`
- Backend workflow: `artifacts/api-server: API Server`
- `pnpm install --frozen-lockfile`
- `pnpm typecheck`

See README.md for source locations, local commands, and build instructions.
No secrets or database are required by the starter.
