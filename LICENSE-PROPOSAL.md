# Proposed source license

MIT is proposed for original Threadline code, consistent with the package metadata. Before publication, the copyright owner should confirm the copyright holder and year, verify contributor and template rights, and approve adding the standard license text as `LICENSE`. [Open Source Initiative MIT License](https://opensource.org/license/mit)

For redistributed bundles or vendored material, inventory each dependency and asset's license and include the required notices. Third-party code and services retain their own terms. This proposal is pending owner approval.
